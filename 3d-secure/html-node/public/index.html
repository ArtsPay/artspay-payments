ArtsPay 3D Secure (fatzebra.js): HTML + Node.js example

Renders ArtsPay's Hosted Payments Page through fatzebra.js with 3D Secure 2 enabled (enableSca: true). fatzebra.js tokenizes the card, runs the 3DS2 check, then submits the purchase itself: this page only reacts to its events, and the backend only ever mints a short-lived OAuth token, it never sees the card or the purchase result directly.

Enter one of the 3DS2 test cards from the guide to see a specific outcome (frictionless, step-up, decline).
